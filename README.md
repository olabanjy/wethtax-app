# 🧩 Wethtax

A modern **React** application setup powered by **Vite**, styled with **Shadcn/UI**, and managed using **Zustand** and **TanStack Query** for global and server state management.

---

## 🚀 Tech Stack

- ⚡ **Vite** — Lightning-fast frontend build tool  
- ⚛️ **React 18+** — UI library  
- 🎨 **Shadcn/UI** — Prebuilt, themeable UI components using Radix & Tailwind  
- 🧠 **Zustand** — Lightweight state management  
- 🔗 **TanStack Query (React Query)** — Data fetching and caching  
- 💨 **Tailwind CSS** — Utility-first styling ..

---

## 🧰 Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (version 18 or higher)
- [npm](https://www.npmjs.com/), [yarn](https://yarnpkg.com/), or [pnpm](https://pnpm.io/)
